Das Web verstehen

Wenn man „das Web“ verstehen will, hilft ein ganz einfaches Bild: Du sitzt an deinem Gerät, gibst eine Adresse ein, dein Browser fragt irgendwo im Internet nach einer Ressource, und ein anderer Computer schickt sie zurück. Aus dieser scheinbar kleinen Aktion entstehen dann HTML, Bilder, CSS, JavaScript und am Ende die sichtbare Webseite. Wichtig ist dabei: Das Internet und das Web sind nicht dasselbe. Das Internet ist die technische Grundlage, also ein weltweites Netzwerk aus vielen verbundenen Netzwerken. Das World Wide Web ist nur ein Dienst, der auf dem Internet läuft und Webseiten per HTTP oder HTTPS zugänglich macht


Browser – Ein Programm, das Webseiten öffnet und anzeigt.

Server – Ein Computer, der Webseiten und andere Daten bereitstellt.
Webseite – Eine Seite im Internet, die im Browser angezeigt wird.
URL – Die Adresse einer Webseite im Internet.


Grundlegende Funktionsweise des Internets: Client, Server und Übertragungswege

Im Kern funktioniert das Internet nach einem einfachen Prinzip: Ein Client fragt etwas an, ein Server antwortet darauf. Dazwischen gibt es Übertragungswege und Geräte, die die Daten weiterleiten.
Stell dir das wie ein Paketversand vor: Du gibst eine Bestellung auf. Die Bestellung wird an ein Lager geschickt. Das Lager schickt dir das Paket zurück. Auf dem Weg dazwischen gibt es Straßen, Verteilerzentren und Transportregeln. Im Web ist es ähnlich, nur dass statt Kartons Datenpakete verschickt werden.

Ein Client ist das Gerät oder Programm, das eine Anfrage stellt. In der Praxis ist das oft dein Webbrowser wie Chrome, Firefox, Safari oder Edge. Wenn du https://example.com eingibst, ist dein Browser der Client. Er fordert vom Server die Webseite an. Ein Client muss nicht immer ein Browser sein. Auch eine App auf dem Smartphone oder ein Programm auf deinem Rechner kann ein Client sein, solange es Daten von einem Server anfordert (How does the Internet work?). Einfach gesagt: Client = fragt an


Reflexion

Was macht der Browser?

Der Browser fordert Webseiten von einem Server an, verarbeitet die Daten und zeigt die Webseite auf dem Bildschirm an.

Was ist eine HTML-Datei?

Eine HTML-Datei ist eine Textdatei mit HTML-Code, der die Struktur und den Inhalt einer Webseite beschreibt.

Welcher HTML-Teil war noch schwierig?

Am Anfang war es noch etwas schwierig zu verstehen, welche HTML-Tags zusammengehören und wo die öffnenden und schließenden Tags stehen müssen.
